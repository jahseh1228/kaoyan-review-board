# 考研复习看板 V2

这是一个面向考研复习的本地离线看板，支持英语一、政治、数学三和经济学专业课。

系统根据间隔复习规则自动生成下一次复习任务，并提供今日看板、未来复习预览、周末离线清单、复习评价、数据同步、Excel 导入导出等功能。

本仓库目前提供一个自包含的一键构建脚本：

```text
build-kaoyan-review-board.ps1
```

即使你没有源码 ZIP，也没有现成的 Windows 离线包，只要保存并运行这一个脚本，就可以自动还原完整源码并生成可双击使用的 Windows 离线 ZIP。

> 构建脚本和源码不包含个人复习记录。学习记录默认保存在浏览器的 IndexedDB 中；如需迁移学习记录，请在看板的“数据同步”页面单独导出 JSON 同步包。

---

## 一、主要功能

### 1. 今日复习看板

系统会根据复习日期、逾期天数、重要度、上次复习结果和每日预算，将任务分为：

- 今日必须完成；
- 正常到期；
- 有余力再做；
- 今日已经完成。

### 2. 间隔复习排期

支持三种复习模板：

- 记忆型：1、3、7、14、30 天；
- 理解型：2、7、14、30 天；
- 做题型：1、3、7、14、30 天。

复习完成后可以评价：

- 忘记；
- 模糊；
- 熟悉；
- 掌握；
- 正常完成。

数学三还支持：

- 独立做出；
- 过程不稳；
- 看提示做出；
- 仍然不会。

系统会根据评价自动计算下一次复习时间。

### 3. 未来复习预览

可以查看：

- 未来 7 天；
- 本周末；
- 未来 14 天；
- 自定义日期范围。

预览会按日期展示任务数量、科目分布、预计时间和预算超量情况。

### 4. 周末离线清单

“未来复习”页面可以生成适合 A4 打印的周末 PDF 清单。

返校后可以按实际完成日期补记周六或周日的复习结果。

### 5. 批量录入

支持多行粘贴录入，可以在保存前：

- 预览解析结果；
- 查看错误行；
- 查看疑似重复项；
- 批量确认；
- 按批次撤销。

### 6. 固定重复任务

支持：

- 每日重复；
- 每周指定星期重复；
- 暂停；
- 恢复；
- 完成记录；
- 计入今日时间预算。

### 7. 数据同步

支持通过 JSON 同步包在不同电脑间合并数据，包括：

- 学习记录；
- 复习历史；
- 设置；
- 固定重复任务；
- 版本向量；
- 冲突处理；
- 导入前自动快照；
- 导入失败回滚；
- 重复同步包识别。

### 8. Excel 与 PDF

支持：

- Excel 快照导出；
- V2 专用 Excel 模板导入；
- 重复文件识别；
- Excel/WPS 打开；
- 周末复习 PDF 下载。

## 二、最简单的安装方法

### 第一步：取得一键构建脚本

在本仓库中打开：

```text
build-kaoyan-review-board.ps1
```

点击 GitHub 页面右上方的 **Raw**，然后：

1. 按 `Ctrl+A` 全选；
2. 按 `Ctrl+C` 复制；
3. 打开 Windows 记事本；
4. 粘贴全部内容；
5. 保存为：

```text
build-kaoyan-review-board.ps1
```

保存时注意：

- “保存类型”选择“所有文件”；
- 文件名不能变成 `build-kaoyan-review-board.ps1.txt`；
- 建议把脚本放入一个新的空文件夹，例如：

```text
D:\考研复习看板构建
```

### 第二步：运行一键构建

在保存脚本的文件夹中打开 PowerShell，然后执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-kaoyan-review-board.ps1
```

第一次运行需要联网。脚本会自动：

1. 从脚本内部还原完整 V2 源码；
2. 校验源码 SHA-256；
3. 下载便携版 Node.js；
4. 根据 Node.js 官方校验文件检查下载内容；
5. 准备固定版本的 pnpm；
6. 安装 `pnpm-lock.yaml` 锁定的项目依赖；
7. 运行单元测试和数据库测试；
8. 执行 TypeScript 与 Vite 生产构建；
9. 从零组装 Windows 离线目录；
10. 加入便携 Node.js；
11. 创建打开和关闭 VBS；
12. 启动生成的应用进行健康检查；
13. 生成可发送、可解压使用的 Windows ZIP。

根据网络速度，第一次执行可能需要数分钟。构建过程中请不要关闭 PowerShell。

## 三、构建完成后会生成什么

脚本运行成功后，当前目录会出现：


各目录用途如下：

| 内容 | 用途 |

| `.kaoyan-build-tools` | 自动下载的 Node.js、pnpm 和依赖缓存 |
| `release\考研复习看板-V2-Windows` | 可直接运行的 Windows 版本 |
| `release\考研复习看板-V2-Windows.zip` | 可发送到其他 Windows 电脑的离线包 |

生成的离线包结构如下：

```text

├── README.html

```

## 四、如何打开看板

进入：

```text
release\考研复习看板-V2-Windows
```

双击：

```text
打开考研复习看板.vbs
```

浏览器会自动打开：

```text
http://127.0.0.1:47831/
```

停止本地服务时，双击：

```text
关闭考研复习看板.vbs
```

离线运行包不要求电脑预先安装 Node.js，因为包内已经带有便携运行时。

---

## 五、重要：不要修改固定地址

请始终使用：

```text
http://127.0.0.1:47831/
```

不要改成：

```text
http://localhost:47831/
```

也不要随意更换端口。

浏览器会把不同的域名和端口视为不同的数据空间。更换地址可能导致看板显示一套新的空数据，看起来像“原来的记录不见了”。

## 六、学习数据保存在哪里

学习记录会保存到本机浏览器硬盘上的 IndexedDB 数据库中。

正常进行以下操作不会删除数据：

- 关闭网页；
- 关闭浏览器；
- 关闭本地服务器；
- 重启电脑；
- 替换新版程序文件；
- 更新离线包中的 `app`。

以下操作可能导致看到另一份空数据或造成数据丢失：

- 改用其他浏览器；
- 改用其他浏览器用户配置；
- 将 `127.0.0.1` 改成 `localhost`；
- 更换端口；
- 清除浏览器站点数据；
- 删除浏览器用户配置；
- 使用无痕模式长期录入。

建议定期进入看板的“数据同步”页面，点击：

```text
导出最新同步包
```

把生成的 JSON 文件保存到安全位置。

程序源码、Windows 离线包和个人学习数据是三种不同内容：

| 内容 | 是否包含个人复习记录 |
|---|---|
| 源码 | 否 |
| Windows 离线包 | 否 |
| 从“数据同步”导出的 JSON | 是 |

不要把个人 JSON 同步包提交到公开 GitHub 仓库。

## 七、同一台电脑从旧版本升级

升级前，先在旧版本的“数据同步”页面导出一份 JSON 备份。

同一台电脑升级时，只要继续使用：

- 同一个浏览器；
- 同一个浏览器用户配置；
- 同一个地址 `http://127.0.0.1:47831/`；

新版就可以读取并升级原浏览器中的本地数据库。

更新程序文件不会主动删除 IndexedDB 中的学习记录。

如果打开新版后出现“首次设置”，请先停止操作，不要：

- 清除浏览器数据；
- 立即重新录入；
- 删除原来的 JSON 备份；
- 反复切换端口。

优先检查是否更换了浏览器、浏览器配置、访问地址或端口。

---

## 八、迁移到另一台电脑

如果需要把学习记录迁移到另一台电脑：

1. 在旧电脑打开看板；
2. 进入“数据同步”；
3. 点击“导出最新同步包”；
4. 把 JSON 同步包带到新电脑；
5. 在新电脑打开看板；
6. 完成首次设置；
7. 进入“数据同步”；
8. 选择同步包；
9. 查看导入预览；
10. 处理可能出现的冲突；
11. 确认合并；
12. 检查学习记录和下一次复习日期。

不要通过复制 Windows 离线包来迁移学习记录。离线包只包含程序，不包含浏览器数据库。


主要目录如下：

```text
.tmp
```

## 十、常见问题

### 1. PowerShell 提示无法运行脚本

请使用完整命令：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-kaoyan-review-board.ps1
```

这个命令只对本次执行放宽脚本策略，不会永久修改 Windows 的全局执行策略。

### 2. 下载 Node.js 或 npm 依赖失败

检查：

- 当前电脑是否可以访问互联网；
- VPN或代理是否影响连接；
- 防火墙或杀毒软件是否拦截 `nodejs.org`；
- 防火墙或杀毒软件是否拦截 `registry.npmjs.org`；
- 系统日期和时间是否正确。

脚本会先尝试使用 PowerShell 下载；如果失败，还会尝试 Windows 自带的 `curl.exe`。

### 3. 提示输出目录已经存在

为了避免覆盖已有源码或离线包，脚本检测到同名输出时会停止。

最简单的处理方式是：

1. 新建一个空文件夹；
2. 把 `build-kaoyan-review-board.ps1` 复制进去；
3. 在新文件夹中重新运行。

### 4. 端口 47831 被占用

先检查考研复习看板是否已经启动。

可以直接打开：

```text
http://127.0.0.1:47831/
```

如果是其他程序占用端口，请先关闭冲突程序。不要自动改用其他端口，否则浏览器会产生另一份本地数据空间。

### 5. 构建测试失败

脚本不会把测试失败的内容当作正式离线包交付。

请保留 PowerShell 中显示的错误信息，再进行排查。不要把未通过测试的 `dist` 手动替换进正式版本。

### 6. GitHub 中复制的脚本运行后提示源码校验失败

通常表示脚本内容没有完整复制。

请重新打开 GitHub 的 **Raw** 页面，确保：

- 从第一行复制到最后一行；
- 中间没有被聊天软件截断；
- 没有手动删除长 Base64 内容；
- 文件扩展名确实是 `.ps1`。

### 7. 双击打开后没有反应

可以依次检查：

1. 是否完整解压了 Windows ZIP；
2. `runtime\node.exe` 是否存在；
3. `app\index.html` 是否存在；
4. 是否被杀毒软件阻止；
5. 端口 47831 是否被其他程序占用；
6. 浏览器能否手动访问 `http://127.0.0.1:47831/`。

### 8. 看板显示空数据

确认：

- 使用的是原来的浏览器；
- 使用的是原来的浏览器用户配置；
- 地址是 `http://127.0.0.1:47831/`；
- 没有改用 `localhost`；
- 没有清除站点数据。

如果是新电脑，需要导入旧电脑导出的 JSON 同步包。

## 十一、安全提醒

- 构建脚本包含源码，但不包含账号密码；
- 构建脚本不包含个人复习数据；
- Node.js 下载后会进行 SHA-256 校验；
- 源码 ZIP 还原后也会进行 SHA-256 校验；
- JSON 同步包可能包含个人学习内容；
- 不要把 JSON 同步包提交到公开仓库；
- 每次重大升级前都应导出一份 JSON 备份；
- 不要通过清除浏览器缓存来处理普通显示问题。

## 十二、推荐工作流

### 普通使用

```text
解压 release 中的 Windows ZIP
→ 双击“打开考研复习看板.vbs”
→ 使用看板
→ 用完后双击“关闭考研复习看板.vbs”
```

### 继续开发

```text
修改 kaoyan-review-board-v2-source 中的源码
→ 运行测试
→ 执行生产构建
→ 生成新的 Windows 离线 ZIP
```

### 迁移学习记录

```text
旧电脑导出 JSON 同步包
→ 新电脑打开看板
→ 数据同步页面导入 JSON
→ 检查记录和下一次复习日期
```

### 重大版本升级

```text
导出 JSON 备份
→ 保留旧版程序
→ 构建新版
→ 使用相同浏览器和固定地址打开
→ 检查记录、历史和下一次任务
→ 确认无误后继续使用
```

如无特殊需要，不要更换固定地址、端口和浏览器配置。
